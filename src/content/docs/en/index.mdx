## What is Verity <span style='color: #E2A845'>BDD</span>?

**Verity BDD** is a Go implementation of the **Screenplay Pattern** for acceptance testing,
focused on API testing. It helps you write tests that read like specifications.

<CardGrid stagger>
  <Card title="Screenplay Pattern" icon="pencil">
    Actors, Abilities, Activities, and Questions — the full Screenplay vocabulary
    for expressive, readable tests.
  </Card>
  <Card title="API Testing" icon="rocket">
    Built-in HTTP API ability for testing REST APIs with a clean, composable interface.
  </Card>
  <Card title="Type-safe Questions" icon="approve-check">
    Generic `Question[T]` interface ensures compile-time correctness for assertions.
  </Card>
  <Card title="Reporting" icon="information">
    Console and Allure reporting out of the box for CI and local runs.
  </Card>
</CardGrid>
